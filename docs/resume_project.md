# 简历项目描述（STAR）

**动态负载感知的稀疏 LIF 计算优化实验｜C++17｜独立开发者**

- **S（背景）**：针对稀疏连接 LIF 网络中大量神经元在单个时间步未接收事件、仍可能被全量扫描更新的问题，探索事件驱动更新在动态负载下的工程收益。
- **T（目标）**：在保持脉冲输出一致和电压数值误差受控的前提下，对比全量扫描、Lazy 更新及动态阈值/迟滞切换策略，测量完整 rollout 内核的性能与适用边界。
- **A（行动）**：独立使用 C++17 实现 CSR 图事件传播、目标去重与累积、延迟衰减状态更新、动态策略选择及正确性基准；设计低转高、高转低、周期突发和中高负载；固定随机种子，采用预热、七次计时取中位数、方法顺序轮换和三次独立进程重复，并归档原始日志及 SHA-256。
- **R（结果）**：动态负载组累计 672 组、留出验证组累计 336 组方法/参考实现正确性比较，归档日志均为零失败，最大电压误差 4.4408920985e-16。在留出验证的四个周期突发配置中，H50_70 相较逐配置事后选择的最佳固定策略，平均观测到约 11.3% 的计时区间缩短；同时识别出中高负载下自适应策略并不稳定占优的边界。

**关键词：** C++17、CSR、事件驱动计算、Lazy Evaluation、LIF、动态负载、自适应切换、迟滞、性能基准、数值正确性、可复现实验。

> 面试说明：11.3% 使用的是逐配置事后 oracle（`min(FULL, LAZY)`），不是部署时可直接获得的在线基线；实验只代表当前测试环境与样本范围。建议在简历中保留这句限定，体现对指标口径的理解。

**数据口径补充：** 672/336 是三次进程重复累计的策略/参考比较数，不是独立样本数；11.3% 是新种子长序列复核集上多种候选策略比较后得到的探索性最佳观察，尚非预先锁定策略的盲测确认结果。面试时应主动说明这一点。
